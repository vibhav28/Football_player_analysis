# Model Training Guide: YOLOv8 on Roboflow Football Dataset

This guide walks you through training a custom YOLOv8 model on the Roboflow football tracking dataset and deploying the weights to PitchTrack.

---

## 1. Exporting the Dataset from Roboflow
1. Go to your dataset on [Roboflow](https://roboflow.com).
2. Click **Export Dataset** in the top right.
3. Select **YOLOv8** as the export format.
4. Choose **show download code** and copy the Jupyter notebook / Python snippet (it contains your API key).

---

## 2. Setup the Training Environment
We recommend training on a machine with a GPU (e.g., NVIDIA GPU with CUDA, or Apple Silicon Mac).

Create a training folder and install the required dependencies:
```bash
pip install ultralytics roboflow
```

---

## 3. Training Script
Create a script named `train.py` in your training directory. Paste the following Python code to download the dataset and run the training:

```python
import os
from roboflow import Roboflow
from ultralytics import YOLO

# 1. Download the dataset from Roboflow
rf = Roboflow(api_key="YOUR_ROBOFLOW_API_KEY")
project = rf.workspace("YOUR_WORKSPACE").project("YOUR_PROJECT")
dataset = project.version(1).download("yolov8")

# 2. Path to the data.yaml file generated by Roboflow
dataset_yaml_path = os.path.join(dataset.location, "data.yaml")

# 3. Load a pre-trained YOLOv8 model (medium version recommended for speed/accuracy balance)
model = YOLO("yolov8m.pt")

# 4. Train the model
# Using 60 epochs and 1280px resolution for high-resolution broadcast footage
model.train(
    data=dataset_yaml_path,
    epochs=60,
    imgsz=1280,
    batch=8,           # Reduce to 4 or 2 if you run out of GPU memory (OOM)
    device=0,          # Use device=0 for CUDA GPU, 'mps' for Apple Silicon, or 'cpu'
    workers=4
)
```

Replace `"YOUR_ROBOFLOW_API_KEY"`, `"YOUR_WORKSPACE"`, and `"YOUR_PROJECT"` with the details copied from Roboflow.

Run the training script:
```bash
python3 train.py
```

---

## 4. Deploying the Model to PitchTrack
Once the training is complete, YOLOv8 saves the best model weights to:
`runs/detect/train/weights/best.pt`

To use this model in PitchTrack:
1. Copy the `best.pt` weights file into your PitchTrack repository at:
   `app/pipeline/models/best.pt`
2. Open `app/backend/config.py` and set the mock pipeline flag to `False`:
   ```python
   USE_MOCK_PIPELINE = False
   ```
3. Restart the PitchTrack backend server. The pipeline will now run real computer vision analysis on uploaded match footage!
